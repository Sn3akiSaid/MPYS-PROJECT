# BiTeI Topological Phase Transition under a Magnetic Field

MPhys project. Tight-binding study of the topological–trivial phase transition in
**BiTeI**, and the emergence of **Weyl points** when a Zeeman perturbation is applied
across that transition.

## Physics

Two Wannier90 tight-binding Hamiltonians — one topological, one trivial — are
adiabatically interpolated with a parameter α:

```
H(α, k) = (1 − α)·H_trivial(k) + α·H_topological(k) + H_Zeeman(B)
```

The gap closes near a critical **α ≈ 0.786** (18×18 basis). Adding a Zeeman term
`H_Z = B·σ` built from Pauli matrices splits the closing point into Weyl nodes, whose
positions and Berry curvature are then mapped in k-space.

## Layout

| Path | Contents |
|---|---|
| `MODULES/` | Shared library: Hamiltonian I/O, Fourier interpolation, k-mesh generation, Zeeman perturbation |
| `Trajectory B-Field/` | Weyl-point search and Berry curvature in 3D k-space (current) |
| `2D K-mesh B-field/` | Energy/Fermi surfaces on a 2D k-mesh under B (current) |
| `Magnetic Field/` | Perturbed band structure along high-symmetry paths (current) |
| `Hamiltonians 18x18/`, `Hamiltonians 4x4/` | Wannier90 input Hamiltonians — the only non-regenerable data here |

Remaining top-level directories are earlier exploratory work (2024): band
interpolation along L–A–L and L–A–H, orbital projections, spin textures, and bulk
band structures. They are kept for reference and are superseded by the three
programs above.

## Building

Requires `gfortran`, BLAS/LAPACK and an MPI implementation. Each program directory
has its own Makefile:

```bash
cd "Trajectory B-Field" && make
```

The modules in `MODULES/` must be compiled first and are shared by the current
programs. Programs read their Hamiltonians from `Hamiltonians 18x18/` (or `4x4/`);
adjust the path near the top of each source file if needed.

Plotting scripts are gnuplot (`.plt`) and Python (`.py`):

```bash
pip install -r requirements.txt
```

## Data

Simulation output (`.dat`) is **not** tracked — it is regenerated by running the
programs. A small set of `band_partition_*.dat` files is kept in
`Interpolation kmesh/` so the gnuplot scripts run out of the box.

Note that output filenames and run parameters (`B_y`, `np`, `npartitions`, α range)
are hardcoded near the top of each source file and were edited between runs, so a
given historical dataset corresponds to a specific commit rather than to the current
source.
